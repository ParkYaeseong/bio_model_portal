안녕하세요,

GPU 서버에 단백질 모델링 포털을 구축했습니다. 아래 절차로 접속하시면 9개 모델을 웹 UI에서 바로 사용할 수 있습니다.

## 1. 제공되는 모델

| 모델 | 용도 |
|---|---|
| **BioEmu** | 단백질 백본의 동적 구조 앙상블 생성 |
| **ESMFold** | 단일 시퀀스 구조 예측 (로컬 GPU) |
| **ESMFold2** | Biohub Forge API 기반 최신 구조 예측 *(개인 API 키 필요)* |
| **ColabFold** | AlphaFold2 추론 + 로컬 MMseqs2 MSA |
| **RFdiffusion (RFD3)** | 신규/모티프 스캐폴딩/바인더 디자인 |
| **ProteinMPNN** | 백본에 맞는 시퀀스 디자인 |
| **MMseqs2** | UniRef 검색 / MSA |
| **Rosetta Relax** | 구조 완화 (FastRelax) |
| (옵션) AlphaFold2 / DiffDock / PHASTEST | RunPod 클라우드 연동, 별도 키 필요 |

결과는 모두 **웹에서 3D로 바로 보거나** tar.gz로 다운로드 가능합니다.

## 2. 접속 방법

> 운영자: 아래 A / B / C 중 채택한 방식만 남기고 보내세요.

### A. SSH 터널 (가장 간단, 추가 설정 불필요)

본인 PC에서 터미널을 열고 아래 명령을 실행:

```bash
ssh -L 3400:127.0.0.1:3400 -L 8400:127.0.0.1:8400 <발급받은-아이디>@<서버IP>
```

터미널이 연결된 채로 두고, 브라우저에서 **http://localhost:3400** 접속.

> 처음 SSH 접속 시 비밀번호 / 또는 보내드린 키 파일이 필요합니다.

### B. 사내 도메인 (운영자가 nginx로 노출한 경우)

브라우저에서 https://`<도메인>` 접속.

> 사외에서 접속하는 경우 본인 IP를 미리 알려주세요. ACG에 등록 후 접속 가능합니다.

### C. Cloudflare Tunnel (도메인 + Cloudflare Access)

https://`<도메인>` 접속. Google 계정으로 인증 후 포털 진입.

## 4. 사용 흐름

1. 로그인
2. 좌측 모델 카드에서 모델 선택 (예: ESMFold)
3. 작업 제목 입력
4. **시퀀스 모델 (BioEmu/ESMFold/ESMFold2/ColabFold/MMseqs)**: 아미노산 시퀀스 붙여넣기
   **PDB 입력 모델 (ProteinMPNN/Rosetta Relax/RFdiffusion 모티프 스캐폴딩)**: PDB 파일 업로드
   **RFdiffusion 신규 디자인**: Length에 잔기 수만 입력 (예: 100)
5. 제출 → 우측 작업 목록에서 진행 상태 확인
6. 완료되면 **3D 뷰어**로 결과 확인 / artifact 다운로드

각 모델별 입력 필드와 헬퍼 텍스트는 UI에서 한국어로 안내됩니다.

## 5. ESMFold2 사용자: Biohub API 키 발급

ESMFold2만 **외부 API**를 사용하므로 본인 키가 필요합니다.

1. https://biohub.ai 회원가입
2. 계정 페이지에서 **API key 발급** (예: `biohub_xxx...`)
3. 포털에서 ESMFold2 선택 → "Biohub API 키" 필드에 붙여넣기
4. 시퀀스 입력 후 제출

키는:
- **브라우저에만 저장됨** (localStorage)
- 서버 DB에는 저장되지 않음
- "저장된 키 지우기" 링크로 언제든 삭제 가능
- 호출마다 본인 Biohub 크레딧이 차감됩니다
